Things I've shipped

01
LIVE IN PRODUCTION · VERBOLABS

AI-Driven CAT Platform

A computer-assisted translation platform designed and built solo, from empty repo to daily production use.

  • Translates documents across 30+ languages while preserving original formatting, across multiple file types.
  • Dual-portal, role-based design: a linguist workspace and a coordinator portal for assigning files and tracking delivery.
  • Custom MQM quality evaluation: segment- and document-level AI scoring with a GEMBA-MQM-style three-shot prompt and strict JSON schema outputs.
  • Hybrid latency model: single-pass scoring for live edits, full three-pass for background audits, run as async, concurrency-limited jobs with live progress over Socket.io and crash-safe persistence in Supabase.
  • Glossary management, context-aware AI translation, content-hash caching and a golden-set CLI for regression testing.
